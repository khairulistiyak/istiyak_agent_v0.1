## ৩. নতুন তৈরি করতে হবে (2 ফাইল)

### ৩.১ `apps/desktop/src-tauri/src/lib.rs` → `detect_ide_workspaces()` command

**Auto-detect strategy (combined: config + process)**

**Step 1: Check running IDE processes**
```rust
// macOS: ps aux | grep "Visual Studio Code\|Cursor\|IntelliJ\|WebStorm\|PyCharm"
// Windows: tasklist | findstr "code.exe cursor.exe idea64.exe"
// Returns: Vec<String> of running IDE names
```

**Step 2: Parse IDE config files for recent workspaces**

| IDE | Config Path (macOS) | Format |
|-----|---------------------|--------|
| VS Code | `~/Library/Application Support/Code/User/workspaceStorage/*/workspace.json` | `{"folder": "file:///path"}` |
| Cursor | `~/Library/Application Support/Cursor/User/workspaceStorage/*/workspace.json` | Same |
| JetBrains | `~/Library/Application Support/JetBrains/*/options/recentProjects.xml` | XML `<entry key="/path">` |

| IDE | Config Path (Windows) | Format |
|-----|----------------------|--------|
| VS Code | `%APPDATA%/Code/User/workspaceStorage/*/workspace.json` | Same |
| Cursor | `%APPDATA%/Cursor/User/workspaceStorage/*/workspace.json` | Same |

| IDE | Config Path (Linux) | Format |
|-----|---------------------|--------|
| VS Code | `~/.config/Code/User/workspaceStorage/*/workspace.json` | Same |
| Cursor | `~/.config/Cursor/User/workspaceStorage/*/workspace.json` | Same |

**Step 3: Sort by modification time** — `workspaceStorage/*/` folders sorted by mtime DESC

**Step 4: Cross-reference** — only show workspaces for IDEs that are currently running (process check)

**Return type:**
```typescript
interface DetectedWorkspace {
  path: string;       // "/Volumes/SSD/0.1/istiyak_agent_v0.1"
  ide: string;        // "VS Code" | "Cursor" | "JetBrains"
  lastUsed: string;   // ISO timestamp
  isActive: boolean;  // true if IDE is running
}
```

**Edge cases:**
- Multiple IDEs running → return all, UI picks
- No IDE running → return recent workspaces from config + manual picker
- Config file not found → empty list, fallback to manual picker
- Permission denied → empty list, fallback

### ৩.২ `apps/desktop/src/hooks/useWorkspaceDetect.ts`

React hook that:
1. On mount: calls `invoke("detect_ide_workspaces")`
2. Returns: `{ workspaces, activeWorkspace, isDetecting, selectWorkspace, openManualPicker }`
3. Auto-selects most recently used workspace from running IDE
4. Falls back to manual `invoke("select_directory")` via `openManualPicker()`
5. Updates `settingsStore.workspacePath` when selection changes
6. Periodic re-check (every 30s) to detect IDE workspace changes

| Risk | Impact | Mitigation |
|------|--------|------------|
| VS Code config path ভবিষ্যতে পরিবর্তন | Medium | Fallback to manual picker always available |
| IDE not running | Low | Show recent workspaces from config |
| Permission denied on config | Low | Graceful fallback to manual |
| Monaco removal breaks build | Medium | Grep for all imports before deletion |
| Agent tools (read_file, write_file, scan_project) need workspace | Low | Keep Rust commands, only remove UI |
