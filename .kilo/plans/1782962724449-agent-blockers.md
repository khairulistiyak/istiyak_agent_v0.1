# 🔴 Agent কেন কাজ করছে না — সমস্যা ও সমাধান

## Executive Summary

Istiyak AI Companion-এর agent workflow নিম্নলিখিত **critical** সমস্যাগুলোর কারণে চালাতে পারছে না:

1. **Security breach** (private key exposed) ✅ FIXED
2. **OAuth rate limiting bypass** (IP spoofing) ✅ FIXED  
3. **Plaintext credential storage** (no encryption)
4. **Race condition** (dual storage conflict) ✅ FIXED (localStorage split)

---

## ✅ সমস্যা ১: Private Signing Key Git-এ Tracked

**সমস্থা**: `apps/desktop/src-tauri/dev_updater.key` এখনও git-এ tracked।
এটি Tauri auto-updater-এর **private key**।

**সমাধান করা হয়েছে**:
- `.gitignore`-এ `*.key` যোগ করা
- `git rm --cached` কমান্ড দিয়ে untracked করা ✅

---

## ✅ সমস্যা ২: OAuth IP Spoofing

সমস্থা: `apps/saas-backend/src/config/passport.ts`-এ hardcoded `registeredIp: "127.0.0.1"`

**সমাধান করা হয়েছে**:
- `passReqToCallback: true` যোগ করা
- `getClientIp()` helper ফাংশন যোগ করা ✅

---

## 🔴 সমস্যা ৩: Plaintext Secrets Storage

সমস্থা: `~/.istiyak_agent_config.json`-এ API key, JWT token, service account path সবই সাধারণ টেক্সটে সংরক্ষিত

প্রভাব: 
- Config ফাইল চুরি হলে সব কী একসঙ্ক হয়ে যায়
- কোনীভাবে encryption বা secure enclave ব্যবহার হয়নি

সমাধান (ভবিষ্যৎ কাজ):
- Rust-এ `ring` crate ব্যবহার করে AES-256-GCM encryption
- Master key macOS Keychain/Keychain Access-এ রাখা
- সাইন-ড সিকিউরিটি যোগ করা

---

## ✅ সমস্যা ৪: localStorage Secrets Fallback

সমস্থা: `apps/desktop/src/store/slices/settingsSlice.ts:69`-এ localStorage fallback

সমাধান করা হয়েছে**:
- Secrets-এর জন্য `sessionStorage` ব্যবহার করা ✅
- Zustand persist-এ থেকে `apiKey` ও `token` সরিয়ে দেওয়া ✅

---

## ✅ সমস্যা ৫: Dual Storage Race Condition

সমস্থা: Zustand persist IndexedDB-এ সেভ করে, আবার Rust `save_config` `~/.istiyak_agent_config.json`-ও সেইই সেটিংস সেভ

সমাধান করা হয়েছে**:
- Zustand persist-এ থেকে secrets (apiKey, token, serviceAccountPath) সরিয়ে দেওয়া ✅
- non-sensitive config রাখা, secrets আলাদা sessionStorage-এ ✅
