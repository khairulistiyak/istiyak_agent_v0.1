# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability, **do not open a public issue**.

Email: security@istiyak.ai (placeholder — replace with actual address)

Please include:
- Description of the issue
- Steps to reproduce
- Potential impact

## Scope

- API key exposure in logs or URLs
- Command injection vectors
- JWT / auth bypass
- Data leakage between workspaces

We will acknowledge within 48 hours and aim to release a fix within 7 days.
